# Frontend for Krishisetu

This is a Vite + React + TypeScript frontend scaffold using Tailwind CSS.

Run locally:

1. cd frontend
2. npm install
3. npm run dev

Notes:
- Configure environment by creating a .env file at project root or using Vite env variables (VITE_API_BASE) to point to the backend (default http://localhost:8000)
- This scaffold contains auth pages, product listing, and placeholders for cart/bookings. Extend as needed.
